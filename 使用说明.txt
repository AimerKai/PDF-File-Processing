PDF 工具箱 通用版 / PDF Toolkit for Everyone
================================================

【如何使用】
===========
  双击以下任意一个文件即可启动程序：
    - PDF_for_everyone.exe   （主程序，推荐）
    - 启动.bat               （效果同上）

  不需要安装 Python，不需要安装任何依赖。
  支持 Windows 7 SP1 / Windows 8 / Windows 10 / Windows 11。
  （Win7 请确保已安装 KB2999226 / VC++ 2015-2022 Redistributable，Win10/11 自带不用管）

【如果是第一次用，建议先运行】
==============================
  双击 "环境自检.bat" 确认文件完整。

【功能一览】
===========
  1. 合并 PDF       Merge
  2. 拆分 PDF       Split
  3. 压缩 PDF       Compress
  4. 旋转 PDF       Rotate
  5. 裁剪 PDF       Crop     (在某一页框选裁剪，自动应用到所有同尺寸页)
  6. 页面管理       Organize (拖拽排序 / 批量删除 / 旋转 / 提取单页)
  7. 页面检测       Detect   (空白页 + 重复页扫描，一键批量删除)
  8. 提取页面       Extract

【所有功能完全离线】
====================
  不会访问网络，不会上传任何文件，所有 PDF 处理 100% 在本机完成。
  适合公司内网 / 涉密电脑 / 虚拟机环境使用。

【文件说明】
===========
  PDF_for_everyone.exe    主程序
  启动.bat                启动器（效果和双击 exe 一样）
  环境自检.bat            运行前检查文件是否完整
  _internal\              运行库（不要删！里面的 dll 都需要）

【常见问题】
===========
  Q1. 双击 exe 没反应？
  A. 先运行 "环境自检.bat" 看有没有 FAIL。
     如所有检查都通过但仍无法启动，可能是被杀毒软件拦截，
     把本文件夹加入杀毒白名单 / 信任区即可。

  Q2. 报错："This application failed to start because no Qt platform plugin..."
  A. 把 _internal\PyQt5\Qt5\plugins\platforms 文件夹
     复制到 PDF_for_everyone.exe 同级目录（和 exe 放在一起），再试一次。
     如果已运行过 "环境自检.bat"，会自动修复这个问题。

  Q3. 启动很慢？
  A. 首次启动或杀毒扫描时会稍慢（约 3-10 秒），之后每次 1-3 秒，
     属于正常现象。onedir 多文件模式比单 exe 模式启动快很多。

  Q4. 可以把整个文件夹压缩发别人吗？
  A. 可以！把整个 PDF_for_everyone 文件夹打包成 ZIP 发过去，
     对方解压后双击 exe 即可使用。
     不要单独发 PDF_for_everyone.exe（需要 _internal 里的文件）。

  Q5. 公司电脑无法运行？
  A. 公司电脑通常策略更严格：
     1. 把文件夹放在 C:\Users\<你的用户名>\Desktop 或 D:\ 下（不要放桌面公用/网络盘）
     2. 或联系 IT 把本文件夹加入信任
     3. 也可以尝试在 "兼容模式" 下运行 exe（右键-属性-兼容性-Win7/Win8）
